# Arc 0.8.2

Arc 0.8.2 fixes spacing and composition across the generated authentication and admin UI.

- Removes the redundant nested frame from the sign-in page.
- Adds a reusable padded panel body for forms and detail content.
- Applies consistent spacing to profile, user-management, and generated resource forms.
- Keeps data tables intentionally edge-to-edge.
- Extends clean-scaffold browser coverage to prevent nested frames and missing content insets.
