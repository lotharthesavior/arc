# Arc 0.7.0

Arc 0.7.0 introduces composable, opt-in authentication.

- Adds the common `ArcPlugin` registration and setup lifecycle.
- Adds DB identity/roles, browser session, API JWT, and simple RBAC capability crates.
- Gives the identity provider plugin-owned `users`, `roles`, and `user_roles` migrations.
- Adds profile/password editing, first-admin setup, and role assignment.
- Adds `arc plugin add` capability installation.
- Makes generated API and browser resources public by default, with explicit auth and role flags.
- Extends clean-room scaffold verification across public and protected applications.
