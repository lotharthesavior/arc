# Arc 0.7.4

- Render packaged sign-in, profile, and user administration pages through escaped Tera templates
  with accessible, scaffold-compatible form styling.
- Cache the standard session user and apply idle-timeout protection to generated admin routes.
- Add browser coverage for the admin login wall, form layout, profile editing, and user creation,
  plus focused CSRF and HTML-escaping checks.
- Document the generated-app auth storage boundary and fail clearly for unsupported database
  drivers.
