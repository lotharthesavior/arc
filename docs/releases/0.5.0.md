# Arc 0.5.0

Arc 0.5.0 introduces the generated Instrument Panel UI and browser resource scaffolding.

## Highlights

- `arc new <name> --ui` generates Focused public/auth/error pages and a session-protected Dense
  Workbench with semantic design tokens and shared Tera components.
- `arc generate resource <name> --ui` generates collection, detail, create, and edit browser
  pages. Writes dispatch commands and reads use projections.
- Generated resource APIs are JWT-protected by default. `POST /api/session` issues a revocable
  bearer token after bootstrap-admin authentication.
- Production bootstrap authentication requires `ADMIN_PASSWORD_HASH` containing an Argon2 PHC
  string. Plaintext `ADMIN_PASSWORD` is accepted only outside production.
- Clean-room checks cover minimal and UI generation, formatting, Clippy, anonymous API rejection,
  JWT issuance, and authenticated API CRUD.

## Breaking change and migration

Generated resource API endpoints are no longer public. Clients must call `POST /api/session` and
send the returned token as `Authorization: Bearer <token>`. Existing generated applications remain
application-owned and are not rewritten automatically; regenerate or manually wrap `/api` routes
with `JwtMiddleware` when adopting the 0.5.0 contract.

The generated account registration/recovery lifecycle and command-backed profile/settings forms
remain planned follow-up work; this release does not claim those application-owned domain flows.
